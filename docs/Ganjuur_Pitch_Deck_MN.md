# ГАНЖУУР — СТАРТАП ПИТЧ ДЕКК
### GANJUUR: AI-powered Visual Heritage Intelligence for Mongolian Manuscripts

---

## 1. SLIDE — COVER

**Ганжуур** *(Ganjuur)*
*Монгол хөтөлбөрийн дүрслэх ухаанаар суурилсан хэрэглээний цахим номын сан*

**"Хицийн бишрэл, дүрслэх оюун ухаанаар мөрөөдлийг хайж ол"**

Ганжуур бол Монголын арын хөтөлбөрийн *(woodblock manuscript)* хувин шуудууд болон хээ угалзны түүхийг шинжлэх ухаан, технологи хослон судалдаг стартэйп юм.

---

## 2. SLIDE — PROBLEM (Асуудал)

**Монголын хөтөлбөрийн өв — хязгаарлагдмал, эргэлзээтэй нөөц**

| Асуудал | Дүн |
|---------|------|
| 📜 **Төрийн номын дамжуулалт** — Монголын хөтөлбөрийн жинхэнэ эх бичвэрүүд ховор, ихэвчлэн хувийн хэвлэлийн газар төдийгүй гадаад *(BDRC, АНУ-ын номын сан, Хятад улс, Орос улс, Япон улс, Frн Institute)* тархжээ. | Нэг орны харж чадахгүй |
| 🔍 **Хайлтын барьдаг байдал** — Нийт 93,000+ дүрслэл хувинбар байдаг ба тус бүрийг гар аргаар хайж олох нь **хүний нөөцийн** хүндрэлтэй асуудал юм. | Судлаачид жилд 10-20 мин л хайна |
| 🧠 **Хүний алдаа** — Нүдээр уншиж, таних үйлдэл алдаатай, давтагдалтай. Нэг ижилхэн дүрслэлийг оношилоход түлхэлт алдагдал үүсдэг. | **30-50% танилтгүй үлддэг** |
| 🌍 **Эх сурвалж хомсдол** — Локэш Чандра *(Lokesh Chandra)*-гийн цуглуулга *(BDRC MW4CZ5370)* зэрэг цөөн хэдэн эх сурвалжийн дор Монголын ихэнх угалз бичвэр хадгалагдаж байдаг. | Дахин олдохгүй аюултай |
| 💾 **Технологийн зөрүү** — Барууны OCR *(optical character recognition)* Монгол хөтөлбөрийн онцлогоор *(салаа ижил тэмдэгт, босоо бичвэр, дээрээ доош унших)* ажилладаггүй. | Бага төвөгтэй шийдэл |

> **Ерөнхий дүн:** Дэлхийн өндөр соёлт орнууд *(Монгол, Буриад, Төвд, Халим, Хятад)* хамтын өвийг **цаг хугацааны эргэлзээнд** байналддаг бөгөөд маш олон бичвэр танилтгүй хэвээр л байна.

## 3. SLIDE — SOLUTION (Шийдэл)

**Ганжуур — AI дүрслэлийн нүд**

```
[Оруулах] → [DINOv2 Embedding 768D] → [Qdrant Vector DB] → [Хариу]
   ↓              ↓                          ↓                  ↓
 Хуудас       Дүрслэлийн утга           Хэмжсэн төсөөтэй      Ижилхэн
зураг       кодчилол                   хайлт                 хуудас
```

### Хийж чадах зүйлс:

1. **🖼️ Зураг хайж олох** — Нэг хуудас оруулбал түүнтэй төсөөтэй хуудсуудыг Qdrant vector DB-с **0.3 секундын дотор** олно.

2. **🔤 Ижилхэн дүрслэлийг боловсруулах** — Нийт 93,000+ хувинбарын дүрслэлийг DINOv2-base *(768 хэмжээст)* кодчилон хайлтын боломжтой болгосон.

3. **🧬 Угийн байлдвар *(Lineage)*** — Хэдэн арван мянган хөтөлбөрийн ижилхэн дүрслэлүүдэс угийн *(genealogy)* байлдвар бий болгох, аливаа хөтөлбөрийн **хүрээлэл, хөгжлийн замыг** харах.

4. **📖 Үгсийн ангиллал *(Words)*** — Түүхэн баримт бичгийн үгсийн сан бүтээж, хугацаагүй үгсийн хэрэглээг шинжлэх.

5. **🌐 BDRC-тэй интеграци** — Локэш Чандрагийн цуглуулгын IIIF-ийн дагуу мэдээллийг шууд татаж оруулах.

## 4. SLIDE — HOW IT WORKS (Технологийн давуу тал)

**AI дүрслэлийн хайлтын алгоритм**

| Үе шат | Технологи | Онцлог |
|--------|-----------|--------|
| 📷 **Оруулах** | IIIF Image API | BDRC эх сурвалжаас зураг татаж авах |
| ✂️ **Хайрцаглах** *(Crops)* | DINOv2-base (768-D) | Нэг хуудас ~30-50 дүрслэл болгон хуваана |
| 📐 **Кодчилол** | CUDA (GPU-дамжуулна) | Дүрслэлийн дүрслэлийн утгыг 768 хэмжээст вектор болгон кодчилно |
| 💾 **Хадгалах** | Qdrant (Вектор мэдээллийн сан) | 3 цуглуулга: frames (93K+), genealogy (4.7K), words (10K+) |
| 🔍 **Хайлт** | Cosine similarity | Ижилхэн дүрслэлийг хамгийн түрүүнд нээн олно |
| 🌐 **Хэрэглээ** | Gradio Web UI | Хөнгөн, хурдан вэб хэрэглээний интерфейс |

**Яагаад DINOv2?**
- Зураг таних сүүлийн үеийн загвар
- Түүхэн бичвэрүүдэд гүн суралцсан (fine-tune шаардлагагүй)
- GPU дээр хурдан ажиллана

**Яагаад Qdrant?**
- Нээлттэй эх *(open source)* вектор мэдээллийн сан
- 93,000+ vector-г **хагаас минутын дотор** хайна
- Docker-д хялбар суулгана

## 5. SLIDE — PRODUCT (Бүтээгдэхүүний үндсэн онцлог)

### Ганжуурын 3 гол модуль:

**🔹 Нэг: Дүрслэлийн хайлт (Visual Search)**
- Хуудас оруул → түүнтэй төсөөтэй хуудсуудыг жагсаана
- Ижилхэн хээ угалз, ижилхэн текст, ижилхэн хувиргалт
- Confidence score *(итгэлцэл)-ийн* дагуу эрэмбэлнэ

**🔹 Хоёр: Угийн байлдвар (Lineage Analysis)**
- Хэдэн зуун ижилхэн дүрслэл хоорондын холбоос
- Хөтөлбөрийн хүрээлэл, хөгжлийн замыг дүрслэн харуулна
- Монгол харгийн ийн *(Ikh Khüree)* хийгээд хөндий *(Khövsgөл, Gobi)* нутгийн өөрчлөлтийг шинжлэнэ

**🔹 Гурав: Үгсийн сан (Lexicon)**
- Хугацаагүй үгсийн хэрэглээг нэгтгэнэ
- Угалз бичгийн түүхэн хэлбэрүүдийг харуулна
- Лингвистүүдэд зориулсан судалгааны багаж
