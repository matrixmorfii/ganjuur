🔍 3. Визуал Хайлт

  1. Зураг оруулах: "Snippet зураг оруулах" хэсэгт дарж PNG/JPG файлаа сонгоно.
  2. Top K сонгох: Хэдэн үр дүн харах вэ? (санал болгох: 10 эсвэл 20)
  3. Хайх: "Хайх" товчийг дарна (1-3 секунд).
  4. Үр дүн унших: Зүүн дээд талд таны зураг, баруун талд хамгийн төстэй зургууд эрэмбээр гарна. Доор нь ижилсэх хувь (%) харагдана.

💡 Зөвлөмж

95%-с дээш ижилсэлтэй бол ижил үсэг байх магадлал маш өндөр. Эргэлзээтэй үсгээ шалгахдаа энэ функцийг байнга ашиглаарай.

📊 4. Чанарын Хяналт

  1. Тооцоолох: "UMAP/LOF тооцоолох" товчийг дарна. (30-60 сек хүлээнэ)
  2. График унших:
    • 🟢 Ногоон цэгүүд = хэвийн, олноороо бөөгнөрсөн
    • 🔴 Улаан цэгүүд = гажилт (outlier), буруу галиглагдсан эсвэл онцгой хэлбэр
  3. Цэг сонгох: Дурын улаан цэг дээр дарна → баруун талд том зураг, галиг, метадата гарна.
  4. Шалгах: Зургийг эхтэй нь тулгаж, буруу бол шууд засаад "Хадгалах" дарна.

⚠️ Анхааруулга

UMAP тооцоолж байх үед сервер ачааллаж, бусад хэрэглэгчийн "Хайх" үйлдэл удааширч магадгүй. Үүнийг өдрийн ажлын төгсгөлд хийгээрэй.

✍️ 5. Галиглах - Гол ажлын урсгал

  1. Шүүлтүүр сонго: Дээд талд "Боть" → "Хуудас" → "Мөр" сонгоно.
  2. Зураг сонго: Зүүн жагсаалтаас ажиллах snippet дээр дарна. Голд томоор харагдана.
  3. Текст бичих: Баруун талын "Галиг" талбарт Тод үсгийг кирилл хөрвүүлгийн дагуу яг хуулна.
  4. Товчлол ашиглах: Түгээмэл үгсэд доорх товчийг дарна:
    ТовчОруулах текстЖишээ
    бөгөөдбөгөөдхолбоос үг
    ажгууажгуутөгсгөл залгаас
    мөнмөнмөн
    тэдтэдтэд
  5. Хадгалах: Ctrl + Enter эсвэл "Хадгалах" товч. Систем 100% таарч байж хадгална.
  6. 100% нарийвчлал: Зай, цэг, таслал, урт богино яг таарахгүй бол систем улаанаар сануулж, хадгалахгүй.
  7. Сүүлд хадгалсан: Доод хэсэгт таны сүүлийн 20 үйлдэл хүснэгтээр харагдана. Алдаа гарвал шууд дарж засна.

✓ Шилдэг туршлага

Хадгалсаны дараа систем автоматаар дараагийн зураг руу шилжинэ. Иймд гар дээрээ ажилла: Зүүн гар → сум, Баруун гар → бичих.

💡 6. Ажлын зөвлөмж

  • Хэмнэл: Нэг судлаач өдөрт 30-40 хуудас (800-1000 snippet) гүйцэтгэх нормтой.
  • UTF-8: Шууд системд бичнэ. Word, PDF-ээс хуулж paste хийхгүй – нууц формат орж алдаа үүсгэнэ.
  • Хоосон зай: Үг хооронд 1 зай. Мөр эхэнд/төгсгөлд хоосон зай бүү үлдээ.
  • Цэг таслал: Ганжуурын эх дээрх тэмдгийг яг хуулна. Орчин үеийн "..." "!" зэргийг өөрөө бүү нэмнэ.
  • Эргэлзээ: Таамаглаж бичихгүй. Түр "?" тавиад, багийн ахлагчид Screenshot илгээнэ.
